## 🎯 Принципы хорошего дизайна

### Иерархия
- **Не более 3 уровней** текста в одном блоке
- **Заголовок → подзаголовок → текст** — всегда
- **Крупные элементы** — для привлечения внимания
- **Мелкие** — для деталей

### Отступы
- **Кратны 4px** (4, 8, 12, 16, 20, 24, 32, 40, 48)
- **Не менее 16px** вокруг контента
- **Между секциями** — 80-100px
- **Между карточками** — 18-24px

### Цвета
- **Максимум 3 цвета** в одном компоненте
- **Акцент** (cyan) — только для CTA
- **Основной** (text) — для всего остального
- **Приглушённый** (muted) — для второстепенного

### Типографика
- **Не более 2 шрифтов** (Inter + JetBrains Mono)
- **Letter-spacing** — отрицательный для крупных
- **Line-height** — 1.02-1.1 для заголовков, 1.5-1.7 для текста

### Анимации
- **Всегда** `cubic-bezier(.2,.8,.2,1)` для UI
- **Не более .35s** для UI transitions
- **Никогда не анимировать** `width`/`height` (только transform/opacity)
- **`prefers-reduced-motion`** — обязательно

## 🎨 Дизайн-тренды 2026

**Актуально:**
- Bento grid (Stripe, Apple)
- Double glow (cyan + violet)
- Subtle noise texture
- Micro-interactions
- 3D-tilt на hover
- Animated gradients
- Grainy shadows

**Устарело:**
- Плоский дизайн (flat design)
- Long shadows
- Material Design (кроме mobile)
- Skeuomorphism

## 🚫 Что НЕ делать

- ❌ Не делать яркие цвета (только тёмная тема)
- ❌ Не менять общий стиль (cyan + violet)
- ❌ Не добавлять новые шрифты
- ❌ Не использовать эмодзи (кроме user-flow)
- ❌ Не отвлекать анимациями (subtle only)
- ❌ Не увеличивать больше 25% (иначе сломает баланс)
